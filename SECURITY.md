# Security Policy

Memento performs local maintenance operations, so path validation, operation freshness, recovery behavior, and privilege boundaries are security-sensitive.

## Reporting a Vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private security advisory form for this repository:

https://github.com/Cailiang/memento-client/security/advisories/new

Include the affected Memento version, macOS version and architecture, the smallest reproducible sequence, expected and actual behavior, and whether any file, application, service, credential, or configuration was exposed or modified. Remove API keys, usernames, complete private paths, prompts, file contents, and application inventories unless a maintainer explicitly requests them in the private advisory.

We will acknowledge a complete report, assess impact, and coordinate remediation and disclosure through the private advisory. Do not test against machines or data you do not own.

## Supported Versions

Security fixes are provided for the latest published macOS release. Windows and Linux builds are internal portability artifacts and are not supported maintenance products.
